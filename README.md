# Taller Mecánico "El Pistón"

Pequeño sitio web de servicios.

- `index.html` – página principal con menú y descripción de 2 servicios
- `mantenimiento.html` – Servicio 1: Mantenimiento de autos (Estudiante 1, rama `feat/detalleservicio1`)
- `lavado.html` – Servicio 2: Lavado y detallado (Estudiante 2, rama `feat/detalleservicio2`)
- `style.css`, `script.js`, `img/`

## Flujo de trabajo

```bash
git checkout main
git pull origin main
git checkout -b feat/detalleservicio1   # o feat/detalleservicio2
git add .
git commit -m "mensaje"
git push origin feat/detalleservicio1
```
